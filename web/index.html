Sesiones Usuarios — Detectando… Iniciando

Conexión

Sustituto del Monitor Serial de Arduino IDE. Funciona en Windows, Linux, macOS y Chrome Android (USB-OTG).

Este sitio no está en contexto seguro. Web Serial requiere HTTPS o localhost. En el celular usa la URL HTTPS del servidor.

Dispositivo: —

Al abrir el puerto en Linux/macOS puede pulsar DTR y reiniciar la placa.

Android: usa Chrome (no Serial USB Terminal abierto), cable OTG y esta página por HTTPS. El CH340 no aparece en Web Serial; se usa WebUSB. Acepta el permiso “USB” al pulsar Elegir puerto.

Código del equipo

Detecta la serie actual por serial, genera el código ZG con la API y lo escribe al dispositivo.

Diagnóstico serial superusuario

Si el monitor se queda mudo, aquí se ve si el stream cerró (done), falló getReader, hubo overrun o el bucle murió. Usa Reabrir puerto para recuperar.
